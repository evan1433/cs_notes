# Go 开发学习路径

本系列面向已经了解变量、函数和循环，希望独立开发与维护 Go 后端服务的读者。
先理解语言行为，再练习并发与资源管理，最后完成可测试、可诊断的服务。
文中的“完成”以能够解释失败原因、验证边界行为为准。

## 环境与使用方式

- 语言示例最低要求 Go 1.24；系列验收使用 Go 1.27.4。安装参考 [Go 官方安装指南](https://go.dev/doc/install)。
- 数据库示例使用 PostgreSQL 17.12，Go 驱动固定为 `github.com/jackc/pgx/v5 v5.7.6`。
- 每篇中的独立示例放入单独目录；同一示例的多个文件放在一起，不要把所有 `main` 函数合并。
- 示例代码保留在文章内；Docker、网络、数据库等额外条件在对应文章注明。
- 实际维护时升级受支持的 Go、数据库与依赖版本，并重新执行测试；固定版本用于复现，不代表长期免维护。

## 编写与复习步骤

1. 阅读概述与前置知识，先写下这一篇需要解决的问题。
2. 按文件名复制完整示例，运行成功路径，记录预期结果。
3. 执行文章中的失败用例，解释错误在哪一层处理、资源由谁释放。
4. 完成自测练习，用测试或诊断数据验证结论。
5. 返回索引，检查是否具备当前阶段的验收能力，再进入下一阶段。
