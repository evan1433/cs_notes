# 什么是 OpenSearch
OpenSearch 是一个开源的**分布式搜索与分析套件**，主要用于全文本搜索、日志分析、可观测性和安全分析等场景。它基于 Apache Lucene 构建，采用 Apache 2.0 许可证，由 Linux 基金会下的 OpenSearch 软件基金会维护，不存在供应商锁定问题。

### 核心组件与架构

OpenSearch 并非单一软件，而是一套工具集：

*   **OpenSearch Core**：核心搜索引擎，负责数据存储、索引和查询，具备分布式、可扩展和容错的设计。
*   **OpenSearch Dashboards**：可视化用户界面，用于探索数据、创建图表和仪表盘。
*   **Data Prepper**：服务端数据收集器，用于在数据进入 OpenSearch 前进行过滤、转换和丰富。

在架构上，它通过**集群**、**节点**、**索引**和**分片**来组织数据。索引被分割成多个分片分布在不同节点上，并配有副本分片以保证高可用性和查询吞吐量。

### 关键能力与场景

OpenSearch 支持多种检索方式，并广泛应用于多个领域：

*   **混合搜索**：结合传统关键词搜索（BM25）与基于向量的语义搜索，提升结果相关性，也常用于构建 RAG（检索增强生成）应用。
*   **可观测性**：集中分析日志、指标和追踪数据，用于监控应用与基础设施的健康状况。
*   **安全分析（SIEM）**：用于威胁检测、事件调查和安全分析。
*   **向量数据库**：内置向量引擎，支持 k-NN 搜索，可处理数十亿级别的向量数据，为 AI 应用提供支持。

### 主要特点

*   **完全开源**：采用 Apache 2.0 许可证，允许自由修改、扩展和商业化使用，无供应商锁定。
*   **可扩展性**：通过横向扩展（增加节点）和纵向扩展来应对数据增长，分布式设计支持处理海量数据。
*   **丰富的插件生态**：提供告警、异常检测、SQL 支持、地理空间分析等多种内置插件，可按需启用。

> **背景补充**：OpenSearch 最初源于 2021 年亚马逊对 Elasticsearch 7.10.2 及 Kibana 7.10.2 的开源分支，旨在提供一个由社区驱动且保持完全开源的替代方案。
